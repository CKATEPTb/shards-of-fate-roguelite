# Браузерный клиент

Первый игровой срез использует React и Phaser 3 с Canvas-рендерером.
Статический пиксельный лес рисуется кодом и один раз сохраняется в текстуру.
Ходы и исход боя рассчитывает отдельное детерминированное ядро.

В прототипе визуальный цикл ограничен **30 кадрами/с** для устойчивой работы
на мобильных устройствах и в программном рендерере браузера. Это временное
ограничение косметических анимаций; оно не меняет скорость или результаты
симуляции. Цель спецификации для версии 1 — **60 кадров/с** — остаётся задачей
последующей оптимизации и профилирования.
