# Проверки ускоренного баланса

## Код и данные

- `npm run build` — успешно: TypeScript и production-сборка клиента. Сохраняются предупреждения сборщика о размере чанков и браузерном импорте `node:net` из rsocket.
- `npm run validate` — успешно: 9 героев, 550 врагов, 490 навыков, 150 аур, 4 861 предмет и 509 комплектов, включая стартовые.
- Целевой набор — **172 теста в 10 файлах, все прошли**. Проверены правила завершения похода, масштабирование лечения врагов, личная добыча, выбор действий, модель похода, статистика отчётов и завершение рабочих процессов.
- В этот набор входят **108 парных боёв**: 9 сидов × 4 размера отряда × 3 сложности. Сохранение посреди боя и продолжение дают тот же конечный результат, что непрерывная симуляция: события, кубики, состояния тела, щиты, ауры и перезарядки совпадают.

Команда целевого набора:

```sh
npx vitest run tests/balance- tests/simulation-policy.test.ts tools/balance-simulator/src/campaign-engine.test.ts tools/balance-simulator/src/campaign-worker-lifecycle.test.ts packages/game-core/src/__tests__/combat.test.ts
```

## Полная существующая тестовая база

Полный запуск завершился: **2 377 успешных тестов, 544 ошибки, 1 пропуск** (2 922 теста). Ошибки находятся в 31 файле старых проверок: модели, прежние правила анатомии/автобоя, сохранения, мир и старый сетевой протокол. Это не зелёная полная тестовая база. Подробности: `balance-full-suite.json`; исходная диагностика до настройки: `baseline-test-failures.txt`.

Полный запуск был выполнен до добавления отдельной матрицы из 109 тестов детерминизма; её результат включён в целевые 172 теста выше. Суммировать эти наборы как независимые проверки нельзя.

## Совместимость сохранений

Новый контент имеет хеш `46142700`, прежний — `5211d046`. Старые одиночные и сетевые сохранения существующий загрузчик отклоняет. Проверено, что исходная запись остаётся в хранилище; начало нового похода перезаписывает единственный слот. Автоматической миграции старого баланса нет. Простого разрешения старого хеша недостаточно: у незаконченных боёв изменились максимумы здоровья врагов. Новые сохранения проходят проверку продолжения.

## Индексация и процессы

Запущенный для этой задачи отдельный сервер Codebase Memory, PID 28664, завершён; его выход проверен. Вспомогательный процесс индексации PID 10792 также завершён. Процессы, существовавшие до задачи, сохранены, включая общий daemon PID 24452. Общий daemon продолжает обслуживать прежние сессии и автоматически запускает свою индексацию; он не остановлен. В доступном наборе инструментов отдельного API освобождения сессии не было.

Симуляторы завершают собственные рабочие процессы после расчётов. Итоговые серии содержат контрольные суммы исходников до и после выполнения; результаты с изменившимися исходниками отмечаются как непроверенные.
