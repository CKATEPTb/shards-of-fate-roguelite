# Phase 0–1: проверка первой поставки

Дата: 2026-09-19. Node.js 24.14.1, Windows; Playwright Chromium 153.

## Проверенные результаты

| Проверка | Результат |
| --- | --- |
| `npm run validate` | 3 героя, 10 врагов, 18 навыков, 2 эффекта, 7 статусов, 5 встреч |
| `npm test` | 90 тестов, 8 файлов — успешно |
| `npm run typecheck` | Успешно |
| `npm run build` | Успешно; React shell и Phaser разделены |
| `npm run test:e2e` | 5 сценариев — успешно |
| `npm run simulate -- --runs 100` | 3500 боёв, все завершились |

E2E проверяет завершение боя победой и поражением, изменение состава, запуск/паузу/продолжение, пошаговое управление, одинаковый replay, восстановление сохранения без потери состояния и отклонение повреждённого сохранения без изменения текущего боя. На viewport 390×844, 844×390 и 320×740 доступны управление и карточки; горизонтального переполнения нет. Это браузерная эмуляция размеров, не сертификация на физических мобильных устройствах.

Интеграционные тесты перебирают все 7 непустых составов отряда и все 5 встреч на нескольких seeds. Проверяются конечность боя, границы HP/щита, последовательность событий и побитовое равенство восстановленного будущего состояния. Отдельные тесты защищают от изменения входного состояния, конфликтов схем, неизвестных ссылок, циклов триггеров и несовместимых snapshots.

## Найдено и исправлено

- Критический удар определяется видимым d20; отдельного скрытого процентного броска нет.
- При нескольких провокациях побеждает защитник с большим текущим HP.
- Составной навык удерживает исходную цель; после её гибели горение/яд не перескакивает на следующую.
- Snapshot содержит fingerprint игрового контента; изменение механик делает старое сохранение несовместимым.
- Терминальные эффекты корректно учитываются при финализации и восстановлении боя.
- React StrictMode не оставляет второй Phaser canvas; создание/очистка сцены разделены.
- Статичный лес отрисовывается в текстуру, временные надписи и анимации очищаются при сбросе.

## Баланс

Канонический воспроизводимый отчёт: [balance.json](balance.json). 3500 боёв = 5 встреч × 7 составов × 100 seeds с префиксом `balance-v1`. В отчёте сохранён fingerprint контента.

Итог: 1960 побед, 1536 поражений, 4 ничьи. Полный отряд выигрывает первые четыре встречи в 100% проверенных seeds и элитную — в 53%. Ничьи в этом прогоне возникают из-за одновременного выбытия сторон от периодических эффектов. Поздние встречи пока не сбалансированы для каждого одиночного героя; здесь ещё нет развития через экипировку. Это исходный боевой стенд, не финальный баланс Run.

## Границы поставки

Игра запускается локально без backend. RSocket multiplayer, мир/переходы, таймер акта, экипировка, loot draft и три акта ещё не реализованы; они явно отмечены в checklist. Snapshot подготовлен для локального восстановления и будущего сетевого протокола, но не является реализацией host migration.

Phaser вынесен в отложенно загружаемый bundle (~323 KB gzip); Vite сообщает о размере этого чанка. UI использует Google Fonts с системными fallback-шрифтами. CI-конфигурация добавлена; облачный CI не запускался, локальные эквивалентные команды выполнены.
