# План реализации

Источник: [исходная спецификация](specification/MASTER_GAME_SPECIFICATION.md). При расхождениях действуют подтверждённые ADR. Исходный документ сохранён без редактирования.

## Phase 0 — Основа

- [x] npm workspaces: client/server, game-core/game-data/protocol/shared, инструменты.
- [x] Строгие TypeScript-контракты, schemaVersion и runtime-валидация контента.
- [x] Независимые именованные RNG streams; сериализуемое состояние.
- [x] Версионированные intents и проверка последовательности событий.
- [x] CI: validator, typecheck, unit/integration tests, production build.
- [x] ADR: границы этапа, авторитет симуляции, необратимый маршрут.

## Phase 1 — Вертикальный боевой срез

- [x] Dice parser, инициатива, попадания/криты/броня.
- [x] Декларативные AI, навыки, эффекты, статусы и cooldown.
- [x] Защита от бесконечных цепочек триггеров.
- [x] Страж, Жрец, Маг; 10 типов врагов; набор встреч.
- [x] React HUD и Phaser pixel-art арена; результаты боя.
- [x] Seed replay, pause/step/speed, события бросков в симуляции, snapshot save/load.
- [x] Headless balance simulator и воспроизводимый отчёт.
- [x] Проверки браузера на desktop и mobile viewport.

## Следующие этапы

- Приоритет изменён пользователем: [карта и игровой экран перед сетью](adr/0004-map-first-game-shell.md).
- [x] World graph: круговой Act I, четыре сезона, независимые пути к зиме.
- [x] Участки 35×35, физические преграды, глобальная достижимость всех областей, выходов и POI.
- [x] Несколько парных проходов, лабиринты с петлями и отдельные области с обходом через соседний чанк.
- [x] Направленные анимации всех текущих героев и врагов: покой, ходьба, действие, урон и падение.
- [x] Общая длительность шага и интерполяции, плавное сопровождение камерой, пауза и корректный сброс движения.
- [x] Высокие сезонные деревья, кусты, заросли и камни с сортировкой глубины и прозрачностью при перекрытии.
- [x] Локальный A*, движение только своего героя по клику/тапу (включая клики по союзникам), переход всем отрядом.
- [x] Встречи на карте → бой → продолжение исследования; зимний алтарь как цель исследования.
- [x] Детерминированное восстановление мира и движения из сохранения.
- [x] Генератор v3: 10–15 колец на сезон, радиус 40–60 чанков, создание геометрии по мере исследования.
- [x] Дома, руины, колодцы и поселения с физическими стенами, дворами и проходами.
- [x] Общий рисунок окружения мира и боя; опора персонажей на землю, ветер и рябь.
- [x] Мягкий свет вокруг каждого героя и костров, тёмные дальние участки.
- [x] Камера всегда плавно следует своему герою без ручного перемещения, кнопки возврата, зума и выхода за карту.
- [x] Информационная мини-карта ближайших 7×7 участков, без атласа, выбора перехода и прокрутки карты.
- [x] Property tests: 10 000 сезонных профилей, 10 000 реальных чанков с проходами; полная потоковая проверка больших миров.
- [x] Игра на весь viewport; меню справа снизу, без отдельных экранов карты, героев и журнала.
- [x] Информационные панели поверх игры: герои слева, мини-карта и мировые X/Y справа; наведение и клики сквозь HUD.
- [x] Два столбца значков своего героя слева снизу: 11 пустых ячеек экипировки, неназначенная раса, «Вызов», «Несокрушимый бастион», «Защита союзников» и два дополнительных пустых слота; подсказки пропускают ввод в мир.
- [x] Узкие тропы между выходами каждой доступной области: естественные участки, утоптанная земля и мелкая брусчатка без широких наложений.
- [x] Деревянные полы, согласованные стыки стен и крыши по размеру дома, полностью закрывающие задние стены.
- [x] Редкие непрозрачные валуны и низкие формации 2×2/2×3/3×2/3×3; прозрачность только над проходимой землёй.
- [x] Стрелки выходов поверх окружения и указатели у всех четырёх краёв окна, без отступа под старую панель и с пропуском ввода в мир.
