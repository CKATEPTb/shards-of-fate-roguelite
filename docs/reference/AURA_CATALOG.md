# Каталог аур

150 определений: 11 ранее существовавших и 139 новых. Каждое из 15 семейств содержит 10 аур.

Все 150 аур подключены к доступным навыкам или пассивным эффектам. Проверка `npm run validate` обнаруживает определения без игрового источника; отдельные runtime-тесты подтверждают наложение всех аур через боевую логику. Добавление определения само по себе не выдаёт ауру персонажу и не меняет стартовую экипировку.

## Применение

- Ссылка на ауру — её стабильный `statusId` из таблицы.
- `defaultDuration` — рекомендация для авторов контента и начальный параметр мастерской. Фактическую длительность применения задаёт `action.duration`; она не подменяется автоматически значением из каталога.
- Числовая длительность считается в собственных ходах носителя. `null` означает отсутствие срока, однако у `burning` заряд расходуется после каждого тика.
- `independent`: отдельные экземпляры со своим сроком и отдельными действиями; числовые модификаторы суммируются. `refresh`: тот же источник обновляет существующий экземпляр. `decay`: общий запас зарядов уменьшается после тика.
- Для `vampirismDice`, `healingShareDice`, `partyGuardDice`, `preserveHot`, `preserveShield` и `repeatAttack` действует последнее активное правило соответствующего вида. Эти правила не создают дополнительные проверки от каждого экземпляра. `damageBonusDice` бросается отдельно для каждого экземпляра.
- Броски периодической ауры используют последовательность её источника. Периодический урон с кубиками сохраняет плоский бонус к урону источника; фиксированный `damagePerStack` Горения его не получает. Локальная броня и другие правила защиты действуют, если описание не указывает обход брони.
- Во всех масштабируемых действиях используется единая Сила источника: `max(0, power + powerBonus)`. Отдельной силы лечения нет. Действия без масштабирования не получают Силу; дополнительные кубики урона также не добавляют её повторно.
- `accuracyBonus` меняет Точность, `critBonus` — Критический удар, `resilienceBonus` — Стойкость. Попадание и крит проверяются разными `1d20` по [действующим правилам боя](COMBAT.md). Периодические тики не бросают попадание или крит. Крит прямого урона/лечения удваивает весь готовый результат, включая Силу.
- Бонус брони меняет эффективную локальную защиту поражённой части: защитник бросает по `1d20` за полные двадцатки и `1dR` за ненулевой остаток, включая `1d1`. Это не постоянное вычитание всего числа брони.
- `visual` описывает внешний вид, движение и частицы. Анимация не потребляет боевые кубики.
