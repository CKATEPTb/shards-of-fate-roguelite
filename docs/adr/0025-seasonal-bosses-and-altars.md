# 0025 — Сезонные боссы, таймер и алтари

## Решение

В первом акте доступно 50 боссов: 13 весенних, 13 летних, 12 осенних и 12 зимних. В каждом походе выбирается по одному боссу сезона. У каждого есть собственное основное умение и два дополнительных; всего добавлено 66 умений для боссов. Они используют действующие кубики, ауры, снаряды и семейства пиксельных спрайтов. Боссы исключены из обычных, водных и подвальных пулов противников.

### Призыв

- Порядок всегда один: весна → лето → осень → зима.
- Первый отсчёт начинается при создании похода. Интервал на каждой сложности — 20 минут активного игрового времени, 30 000 тиков по 40 мс.
- После любого призыва следующий сезон получает полный интервал. Победа над текущим боссом для запуска следующего отсчёта не требуется. После четвёртого призыва таймер больше не запускается.
- По истечении таймера отдельный кубик по сиду выбирает живого героя. Герои сортируются по постоянным ID. Босс появляется на ближайшей свободной достижимой клетке рядом с ним; при полностью занятом окружении используется клетка героя.
- Бой вовлекает только свободных героев в доступности pathfinder до десяти клеток. Герои в других чанках продолжают свой поход. Если выбранный герой уже сражается, босс остаётся рядом и может напасть после текущего боя; свободные герои поблизости могут вступить сразу.
- Босс может остаться в мире после ухода героев. Его чанк и живой экземпляр сохраняются, пока босс не побеждён.

### Алтари и интерфейс

В каждом сезоне ровно один алтарь. Зимний сохраняет прежнее место в графе; остальные выбираются независимым RNG по сиду и размещаются после основной генерации геометрии. Поэтому добавление алтарей не перестраивает сохранённые дома, выходы, препятствия или обычные встречи.

Нажатие на алтарь прокладывает маршрут, если нужно приблизиться. У алтаря текущего сезона открывается подтверждение «Хотите действительно призвать босса?». Только подтверждение отправляет `interact` и вызывает босса рядом с нажавшим героем. Прохождение через клетку алтаря ничего не делает. Алтари будущих сезонов недоступны до своей очереди, а уже призванный сезон нельзя вызвать повторно.

Поверх сцены отображаются небольшое название сезона, оставшееся время и тонкая полупрозрачная полоска. Бой и окно наград не скрывают таймер. На миникарте алтарь раскрывается после посещения участка. Новый призыв показывает имя босса и героя, рядом с которым он появился; загрузка и переподключение не повторяют старые уведомления.

### Детерминизм и сохранения

Протокол комнаты повышен до v11. Автоматический призыв передаёт компактное событие `boss-summon`; ручной использует существующее `interact`. Состав босса, выбор героя, размещение и начало боя вычисляются одинаково на всех клиентах. Таймер использует общие игровые тики и не требует отдельного сетевого сообщения каждую секунду.

Босс выбирается отдельным кубиком сущности `season-boss:<season>`, герой для автоматического призыва — `season-summon:<season>`. Вид босса одинаков для алтаря и таймера при одном сиде. Эти броски не меняют последовательности героев. В бою босс использует обычный личный счётчик врага, начинающийся с нуля для нового боя.

Снимок хранит следующий срок, четыре небольшие записи призыва, живые группы и ID убитых боссов. Выход из похода останавливает его игровое время; продолжение сохраняет оставшийся отсчёт. Старое сохранение без сезонного прогресса получает полный первый интервал от сохранённого тика. Добавление каталога совместимо с прежним содержимым и надетой экипировкой.

### Завершение

Победа наступает после гибели всех четырёх сезонных боссов. Другие уже начавшиеся бои отряда завершаются перед итоговым экраном, чтобы ни один из них не завис. Участники победного боя получают обычную персональную добычу босса; её можно разобрать перед итоговым окном. Алтарь сам по себе больше не завершает поход.

## Проверка и ограничения

Пройдены проверка типов, production-сборка и проверка схем и ссылок каталога. Автоматические тесты и игровое прохождение на двух устройствах в этой задаче не запускались. Начальные параметры боссов требуют игрового прохождения для настройки сложности; 50 новых отдельных моделей не создавалось.
