# ADR 0028: ускоренная проверка баланса похода

## Решение

Баланс проверяется по завершению четырёх сезонных боссов, отдельно для отрядов из 1–4 разных героев и трёх сложностей. Ориентиры: около 30% / 15% / 5–10% побед и 60–90 минут успешного похода. Показатели относятся к явно описанной стратегии симулятора; они не заменяют наблюдения за игроками.

Симуляция работает с виртуальными часами. Переходы между событиями мгновенны; боевые анимации учитываются только при расчёте игрового времени. Правила боя, броски каждого существа, личная добыча, экипировка и повреждения берутся из game-core. Проекция контента ускоряет вычисления без изменения определений участвующих существ, способностей и эффектов; эквивалентность проверяется тестами.

Бот принимает решения по текущему состоянию и математическому ожиданию известных кубиков, не читая будущие броски. При отсутствии явно переданной политики игровой бой по-прежнему ожидает действия игрока.

Для масштабных серий используются отдельные процессы с ограниченным числом походов в каждом: кэши миров освобождаются вместе с процессом. Отчёты содержат начальный и конечный отпечатки исходников, хеш контента, сиды, интервалы уверенности и разбиение по составам. Ошибочные расчёты прерывают серию. Проверочные сиды отделены от калибровочных.

## Изменения игровых правил

- При уменьшенном для малого отряда здоровье врага его лечение и щиты уменьшаются пропорционально фактическому масштабу здоровья при создании врага, максимум до исходной величины. Множитель сложности исключается из этого отношения. Присоединение героя не меняет размер уже созданного врага или его лечение. Броски и личные счётчики сохраняются; дополнительные случайные проверки не появляются. Герои используют прежние правила лечения и щитов.
- На каждый поход, героя и редкость сид определяет шесть тематических комплектов. Перед выбором предмета бросается личный `1d5`: 1–4 выбирают доступные вещи этих тем, 5 допускает весь пул редкости. При исчерпании тематического пула используется общий. Уже взятые/пропущенные предметы не возвращаются. Это позволяет собирать бонусы 2/4/6 при большом общем каталоге.
- Редкость по-прежнему повышается отдельными d20 Удачи; гарантии при высокой Удаче сохранены. Тематический отбор не повышает редкость и не навязывает классовое снаряжение.
- Новый бросок добычи требует версии сетевого протокола 13. Формат предметов и личных счётчиков не изменён.
- Интервалы сезонных боссов остаются равны 20 игровым минутам на любой сложности. Ранний призыв через алтарь сохраняет прежние правила.

## Границы

Маршрут, осторожность при выборе группы и время осмотра добычи заданы моделью. Сетевые задержки, случайные подкрепления на пути и поведение людей не имитируются. Контроль без смены стартового снаряжения и отдельный прогон всех типов врагов показывают другие стороны баланса, но тоже не доказывают отсутствие всех возможных чрезмерно сильных сочетаний.

Старая тестовая база содержит проверки отменённого автобоя и прежних правил моделей/мира. Её исходные ошибки записаны отдельно; их нельзя выдавать за успешные проверки новой системы.

Сохранения прежнего баланса (`5211d046`) не проходят существующую проверку хеша нового контента (`46142700`). Проверено для одиночного и сетевого похода: загрузка отказывает, исходная запись остаётся в хранилище. Новый поход перезаписывает единственный слот. Автоматическая миграция старого баланса, особенно незаконченных боёв, в эту калибровку не включена; новые сохранения проходят проверку продолжения.
